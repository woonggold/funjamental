# 🃏 카드 원정대 (funjamental)

포켓몬스터 · 증강체스 · 수집형 RPG에서 영감을 받은 **로그라이크 카드 수집 RPG** 웹 게임 프로토타입.

- 스타터를 고르고, 원정을 떠나 상점에서 카드를 사고, 같은 카드 3장을 모아 ★승급·진화
- 종족/직업 시너지와 속성 상성을 고려해 팀을 짜면 자동 전투
- 이긴 적(보스 포함!)은 포획해서 도감에 영구 등록
- 원정에서 번 보석으로 카드 소환 → 중복은 각성 → 다음 원정이 더 강해짐

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 열면 됩니다.
