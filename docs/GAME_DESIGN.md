# 카드 원정대 — 게임 기획 초안 (v0.1)

> 카드를 **모으고**(수집형 RPG) · **잡고**(포켓몬) · **조합해서**(증강체스) 보스를 깨는 로그라이크 카드 RPG

---

## 1. 한 줄 컨셉

원정을 떠날 때마다 상점과 전투에서 카드를 모아 덱을 키우고 보스를 쓰러뜨린다.
**보스를 포함해 쓰러뜨린 적은 포획해서 영구 컬렉션에 넣을 수 있다.**
원정이 거듭될수록 컬렉션이 두꺼워지고, 더 강한 카드로 다음 원정을 시작한다.

## 2. 영감 → 시스템 매핑

| 영감 | 가져온 것 | 이 게임에서의 형태 |
|---|---|---|
| **포켓몬스터** | 스타터 선택, 속성 상성, 포획, 진화, 도감 | 첫 실행 시 스타터 3종 중 택1 · 7속성 상성표(1.5배/0.75배) · 전투 승리 시 적 카드 포획 · ★승급 시 진화 · 도감 수집률 |
| **증강체스(TFT)** | 상점·리롤, 3장 합성, 시너지, 증강체, 이자, 라이프 | 5칸 상점 + 리롤 · 같은 카드 3장 → ★승급 · 종족/직업 시너지 · 2/5/8 스테이지 클리어 시 증강체 3택1 · 10골드당 이자 1 · 라이프 3 |
| **수집형 RPG** | 뽑기, 등급, 천장, 중복 각성, 재화 | N/R/SR/SSR/UR · 보석 소환(1회/10연차) · 40회 천장 · 중복 획득 시 각성 레벨↑(영구 스탯 보너스) |

## 3. 게임 루프

```
┌──────────────────── 메타 루프 (영구) ────────────────────┐
│  기지: 소환(보석) · 도감 · 원정 준비(컬렉션에서 3장 선택)   │
│        ▲                                    │           │
│   보석 + 포획 카드 도감 등록                     ▼           │
│  ┌──────────────── 런 루프 (1회 원정) ─────────────────┐  │
│  │ 준비(상점·편성) → 자동 전투 → 보상(포획/골드)         │  │
│  │      ▲                          │                 │  │
│  │      └── 수입 ← [증강체 선택] ←───┘                 │  │
│  │ 10 스테이지 클리어 or 라이프 0 → 런 종료              │  │
│  └─────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────┘
```

* **세션 1회 = 원정 1회 (약 10~15분)** 목표
* 원정 결과와 상관없이 무언가 남는다: 포획 카드 · 보석 · 각성 진행

## 4. 핵심 시스템

### 4.1 카드
* 스탯: `HP / 공격 / 방어 / 속도` + 스킬 1개 (마나가 차면 자동 시전)
* 등급: N · R · SR · SSR · UR (상점 가격 1~5골드)
* 속성 1개 + 특성 2개(종족 1, 직업 1)
* **별(★1~3)**: 런 안에서만 유효. 같은 카드·같은 별 3장 = 별 +1 (스탯 ×1.8 / ×3.2)
* **진화**: `evolvesTo`가 있는 카드는 ★승급 순간 진화형으로 바뀐다 (불씨여우 → 화염구미호)
* **각성 레벨(+0~+4)**: 컬렉션에 영구 저장. 뽑기 중복으로 상승, 레벨당 스탯 +6%. 런에서 그 카드를 얻으면 항상 각성치가 반영됨 → **수집이 런의 강함으로 이어지는 연결고리**

### 4.2 속성 상성 (7속성)
| 공격 → | 효과 굉장 |
|---|---|
| 불 | 풀 |
| 물 | 불, 땅 |
| 풀 | 물, 땅 |
| 전기 | 물 |
| 땅 | 전기, 불 |
| 빛 ↔ 어둠 | 서로 1.5배 |

### 4.3 시너지 (서로 다른 카드 종류 수 기준)
* 종족: 야수(공격) · 용족(체력) · 정령(시작 마나) · 기계(방어)
* 직업: 전사(체력+공격) · 마법사(스킬 위력) · 수호자(시작 보호막) · 암살자(치명타, 후열 우선 공격)

### 4.4 전투 (자동)
* 출전 최대 3 → 4(3스테이지) → 5(6스테이지). 앞 2칸 전열, 나머지 후열
* 속도 순 행동 → 평타(마나 +25) / 피격(마나 +8) → 마나 가득 차면 스킬
* 적은 전열부터 노리고, 암살자는 후열부터
* 플레이어 판단은 **전투 전**(편성·배치·구매)에 집중 → 증강체스식 전략

### 4.5 런 경제
* 시작 6골드, 매 스테이지 수입 = 5 + 이자(10골드당 1, 최대 5) + 연승 보너스
* 리롤 2골드, 판매 시 일부 환급
* 패배 시 라이프 -1, 같은 스테이지 재도전 (보스가 관문 역할)

### 4.6 보상 & 포획
* 승리하면 [쓰러뜨린 적 카드 포획 ×2 | 골드] 중 택1
* 보스 스테이지는 **보스 포획 선택지 확정** — 보스 카드는 뽑기로 못 얻음 (전설 포켓몬 느낌)
* 포획 카드는 이번 런에 합류 + 런 종료 시 도감 영구 등록

### 4.7 증강체
* 실버 / 골드 / 프리즘 3티어. 스탯형, 경제형, 조건부(소수 정예, 원소 공명), 규칙 변경형(출전 +1)
* `mods(run)` 훅으로 전투 보정, `onPick(run)` 훅으로 즉시 효과 → 새 증강체는 함수 하나로 추가

### 4.8 뽑기
* 확률 N 52 · R 32 · SR 12 · SSR 3.5 · UR 0.5 (%)
* 1회 30 / 10연차 270 보석, 10연차 마지막 SR↑ 확정, 40회 천장 SSR↑
* 보석은 원정에서만 획득 (스테이지당 15 + 챕터 클리어 150)

## 5. 코드 구조

```
src/
├─ data/          ← 밸런스/콘텐츠는 여기만 고치면 됨
│  ├─ types.ts       공통 타입 (CardDef, CardInstance, Modifiers…)
│  ├─ cards.ts       카드 도감 (스타터·진화형·보스 포함)
│  ├─ elements.ts    속성·상성·등급 색상/가격
│  ├─ traits.ts      시너지 정의
│  ├─ augments.ts    증강체 정의
│  └─ stages.ts      챕터/스테이지, 상점 확률
├─ core/          ← 순수 게임 로직 (DOM 없음 → 테스트/서버 이전 쉬움)
│  ├─ battle.ts      자동 전투 시뮬레이션 + 리플레이 이벤트
│  ├─ run.ts         원정 상태 머신 (상점·합성·진화·보상·증강·수입)
│  ├─ synergy.ts     시너지 계산
│  ├─ stats.ts       별/각성 스탯 계산
│  ├─ gacha.ts       뽑기·천장
│  ├─ save.ts        영구 저장 (localStorage)
│  └─ rng.ts         시드 난수
└─ ui/            ← 화면 (프레임워크 없는 바닐라 TS, 나중에 React/Phaser로 교체 가능)
   ├─ app.ts         화면 전환 + 액션 처리
   └─ components.ts  카드/시너지/HP바 렌더러
```

**설계 원칙**: `data`(무엇) / `core`(어떻게) / `ui`(보여주기) 분리.
전투는 결과를 한 번에 계산하고 이벤트 로그를 UI가 재생 → 나중에 애니메이션·PvP 리플레이·서버 검증에 그대로 사용 가능.

## 6. 로드맵 아이디어

### 단기 (게임이 재밌는지 확인)
- [ ] 드래그 앤 드롭 배치 (지금은 ◀▶ 버튼)
- [ ] 스테이지 맵 분기 (전투/상점/이벤트/휴식 노드 선택 — 슬레이 더 스파이어식)
- [ ] 카드 30~40종으로 확장, 시너지 단계 3단계까지
- [ ] 아이템(장비) 카드: 전투 보상으로 획득, 카드에 장착 (TFT 아이템 조합)
- [ ] 효과음·타격 이펙트

### 중기 (수집 동기 강화)
- [ ] 챕터 2~3 (새 속성 지역, 새 보스)
- [ ] 포획 확률 시스템: 적 HP를 남기고 이기면 포획률↑ 같은 미니게임
- [ ] 도감 완성 보상, 속성별 컬렉션 보너스
- [ ] 일일 원정 (시드 고정 → 모두 같은 맵)
- [ ] 카드 일러스트 (지금은 이모지)

### 장기
- [ ] 비동기 PvP: 다른 유저의 팀 스냅샷과 자동 대전 (전투가 결정론적이라 가능)
- [ ] 계정/서버 저장 (save.ts 교체)
- [ ] 카드 트레이드(유저 간 교환) — 서버 권한 검증 필요

## 7. 밸런스 메모
* 단순 그리디 봇(사면 다 사고 다 올림)이 첫 보스(5스테이지)까지 깨고 6스테이지 정도에서 끝남 → 초반 난이도는 적당한 편, 후반은 전략이 필요
* 조정 손잡이: `stages.ts`의 `power`/`star`, `stats.ts`의 `STAR_MULT`, `gacha.ts`의 확률
