# 카드 원정대 — 게임 기획 초안 (v0.2)

> 카드를 **모으고**(수집형 RPG) · **잡고**(포켓몬) · **조합해서**(증강체스) 보스를 깨는 로그라이크 카드 RPG

---

## 1. 한 줄 컨셉

원정을 떠날 때마다 상점과 전투에서 카드를 모아 덱을 키우고 보스를 쓰러뜨린다.
**보스를 포함해 쓰러뜨린 적은 포획해서 영구 컬렉션에 넣을 수 있다.**
원정이 거듭될수록 컬렉션이 두꺼워지고, 더 강한 카드로 다음 원정을 시작한다.

## 2. 영감 → 시스템 매핑

| 영감 | 가져온 것 | 이 게임에서의 형태 |
|---|---|---|
| **포켓몬스터** | 스타터 선택, 속성 상성, 포획, 진화, 도감 | 첫 실행 시 스타터 3종 중 택1 · 7속성 상성표(1.5배/0.75배) · 전투 승리 시 적 카드 포획 · ★승급 시 진화 · 도감 수집률 |
| **증강체스(TFT)** | 상점·리롤, 3장 합성, 시너지, 증강체, 이자, 라이프 | 5칸 상점 + 리롤 · 같은 카드 3장 → ★승급 · 종족/직업 시너지 · 2/5/8 스테이지 클리어 시 증강체 3택1 · 10골드당 이자 1 · 라이프 3 |
| **수집형 RPG** | 뽑기, 등급, 천장, 중복 각성, 재화 | N/R/SR/SSR/UR · 픽업/상시 배너 · 50회 천장 + 픽업 반천장 · 일일 무료 소환 · 중복 획득 시 각성 |
| **스타크래프트** | 러시/빌드업/수비 운영, 정찰, 상성 | 전략 계열 3종(돌격/성장/요새) 가위바위보 · 전투 전 적 정찰 · 계열별 운영 보너스 |

## 3. 게임 루프

```
┌──────────────────── 메타 루프 (영구) ────────────────────┐
│  기지: 소환(보석) · 도감 · 원정 준비(컬렉션에서 3장 선택)   │
│        ▲                                    │           │
│   보석 + 포획 카드 도감 등록                     ▼           │
│  ┌──────────────── 런 루프 (1회 원정) ─────────────────┐  │
│  │ 준비(상점·편성) → 자동 전투 → 보상(포획/골드)         │  │
│  │      ▲                          │                 │  │
│  │      └── 수입 ← [증강체 선택] ←───┘                 │  │
│  │ 10 스테이지 클리어 or 라이프 0 → 런 종료              │  │
│  └─────────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────────┘
```

* **세션 1회 = 원정 1회 (약 10~15분)** 목표
* 원정 결과와 상관없이 무언가 남는다: 포획 카드 · 보석 · 각성 진행

## 4. 핵심 시스템

### 4.0 전략 계열 (스타크래프트식 3전략) ⭐ 핵심
모든 카드는 3개 전략 중 하나에 속한다. 서로 다른 카드 2종/4종을 모으면 **팀 전체**에 버프가 깔린다.

```
   ⚔️ 돌격 ──이김──▶ 🌱 성장 ──이김──▶ 🏰 요새 ──이김──▶ ⚔️ 돌격
```

| 계열 | 컨셉 | 전투 효과 (2종 / 4종) | 원정 운영 보너스 | 왜 이기나 / 지나 |
|---|---|---|---|---|
| ⚔️ **돌격** | 4드론 러시 | 처음 3~4라운드 공격력 +35%/+70%, 속도↑ | 연승 골드 +1/+2 | 성장이 크기 전에 끝냄 / 요새의 반사·보호막에 막힘 |
| 🌱 **성장** | 빌드업, 버프 깔기 | 매 라운드 공격력 +10%/+18% 누적, 체력↑, 방어·반사 관통 | 승리할 때마다 성장 카드 영구 스탯↑ | 시간이 지나면 요새를 뚫음 / 초반 러시에 무너짐 |
| 🏰 **요새** | 수비 메타 | 피해 반사 10%/20%, 매 라운드 보호막 재생, 방어↑ | 이자 한도 +1/+3 | 러시를 받아침 / 관통+누적 성장을 못 버팀 |

* **정찰**: 준비 화면에서 다음 적의 편성과 전략이 미리 보인다 → 카운터를 짜서 들어가는 플레이
* **보스도 전략이 있다**: 골렘왕(요새 → 성장으로 뚫어라), 폭풍의 제왕(성장 → 돌격으로 빨리 끊어라)
* **오버타임(폭풍)**: 16라운드 이후 매 라운드 모두에게 증가하는 피해 → 요새끼리 무한 대치 방지
* 스타터 3종이 각각 한 전략: 불씨여우(돌격) · 새싹도마뱀(성장) · 물방울거북(요새)

**밸런스 검증 (같은 전력 5인 팀 300판 시뮬레이션)**
- 유리한 상성은 사실상 확정승 → "정찰하고 카운터 치기"가 확실히 보상받음
- 하지만 불리한 쪽이 ★2 카드 1~2장만 있어도 뒤집음 → **상성 vs 성장(경제)** 의 긴장감

### 4.1 카드
* 스탯: `HP / 공격 / 방어 / 속도` + 스킬 1개 (마나가 차면 자동 시전)
* 등급: N · R · SR · SSR · UR (상점 가격 1~5골드)
* 속성 1개 + 특성 2개(종족 1, 직업 1)
* **별(★1~3)**: 런 안에서만 유효. 같은 카드·같은 별 3장 = 별 +1 (스탯 ×1.8 / ×3.2)
* **진화**: `evolvesTo`가 있는 카드는 ★승급 순간 진화형으로 바뀐다 (불씨여우 → 화염구미호)
* **각성 레벨(+0~+4)**: 컬렉션에 영구 저장. 뽑기 중복으로 상승, 레벨당 스탯 +6%. 런에서 그 카드를 얻으면 항상 각성치가 반영됨 → **수집이 런의 강함으로 이어지는 연결고리**

### 4.2 속성 상성 (7속성)
| 공격 → | 효과 굉장 |
|---|---|
| 불 | 풀 |
| 물 | 불, 땅 |
| 풀 | 물, 땅 |
| 전기 | 물 |
| 땅 | 전기, 불 |
| 빛 ↔ 어둠 | 서로 1.5배 |

### 4.3 시너지 (서로 다른 카드 종류 수 기준)
* 종족: 야수(공격) · 용족(체력) · 정령(시작 마나) · 기계(방어)
* 직업: 전사(체력+공격) · 마법사(스킬 위력) · 수호자(시작 보호막) · 암살자(치명타, 후열 우선 공격)

### 4.4 전투 (자동)
* 출전 최대 3 → 4(3스테이지) → 5(6스테이지). 앞 2칸 전열, 나머지 후열
* 속도 순 행동 → 평타(마나 +25) / 피격(마나 +8) → 마나 가득 차면 스킬
* 적은 전열부터 노리고, 암살자는 후열부터
* 플레이어 판단은 **전투 전**(편성·배치·구매)에 집중 → 증강체스식 전략

### 4.5 런 경제
* 시작 6골드, 매 스테이지 수입 = 5 + 이자(10골드당 1, 최대 5) + 연승 보너스
* 리롤 2골드, 판매 시 일부 환급
* 패배 시 라이프 -1, 같은 스테이지 재도전 (보스가 관문 역할)

### 4.6 보상 & 포획
* 승리하면 [쓰러뜨린 적 카드 포획 ×2 | 골드] 중 택1
* 보스 스테이지는 **보스 포획 선택지 확정** — 보스 카드는 뽑기로 못 얻음 (전설 포켓몬 느낌)
* 포획 카드는 이번 런에 합류 + 런 종료 시 도감 영구 등록

### 4.7 증강체
* 실버 / 골드 / 프리즘 3티어. 스탯형, 경제형, 조건부(소수 정예, 원소 공명), 규칙 변경형(출전 +1)
* `mods(run)` 훅으로 전투 보정, `onPick(run)` 훅으로 즉시 효과 → 새 증강체는 함수 하나로 추가

### 4.8 뽑기
* 확률 N 50 · R 33 · SR 13 · SSR 3.4 · UR 0.6 (%)
* 배너: **픽업 배너**(주간 로테이션, 해당 등급 50% 픽업 / 실패 시 다음 확정 = 반천장) + 상시 배너
* 1회 30 / 10연차 270 보석, 10연차 마지막 SR↑ 확정, 50회 천장 SSR↑, 하루 1회 무료 소환
* 소환 기록 100건 저장
* 보석 획득: 원정(스테이지당 15 + 챕터 클리어 150), PvP(승 15 / 패 3)
* ⚠️ 지금은 클라이언트에서 굴림 → 출시 전 Cloud Functions로 이전 필요 (`core/gacha.ts`의 `rollOne` 그대로 이전)

### 4.9 PvP (비동기 → 실시간 확장 가능 구조)
* 원정을 끝낸 팀을 **PvP 덱(스냅샷)** 으로 등록 → 다른 유저의 상대 목록에 노출
* 아레나에서 레이팅 ±250 상대 3명 표시 (전략 + 상성 유리/불리 표시 = 정찰), 부족하면 봇으로 채움
* Elo 레이팅 (K=32)
* **전투가 결정론적**: `(공격 스냅샷, 방어 스냅샷, seed)` → 항상 같은 결과
  * 서버(Cloud Functions)가 같은 seed로 재시뮬레이션해서 조작 검증 가능
  * 리플레이 공유 가능 (seed만 저장하면 됨)
* 실시간 PvP 확장 시: 양쪽이 준비 단계를 같은 시간 안에 끝내고 스냅샷 교환 → 같은 seed로 각자 시뮬레이션 (증강체스 방식)

## 5. 코드 구조 (v0.2)

```
src/
├─ data/doctrines.ts  전략 계열 3종 (돌격/성장/요새)
├─ pvp/
│  ├─ snapshot.ts     팀 스냅샷, PvP 시뮬레이션, Elo, 매치 seed
│  └─ ghosts.ts       봇 상대 생성
└─ net/               백엔드 추상화 (게임 코드는 Backend 인터페이스만 안다)
   ├─ types.ts        Backend 인터페이스
   ├─ local.ts        오프라인/게스트 (기본)
   ├─ firebase.ts     Google 로그인 + Firestore (환경변수 있으면 자동 사용)
   └─ index.ts        createBackend()
```

## 5-1. 기존 코드 구조 (v0.1)

```
src/
├─ data/          ← 밸런스/콘텐츠는 여기만 고치면 됨
│  ├─ types.ts       공통 타입 (CardDef, CardInstance, Modifiers…)
│  ├─ cards.ts       카드 도감 (스타터·진화형·보스 포함)
│  ├─ elements.ts    속성·상성·등급 색상/가격
│  ├─ traits.ts      시너지 정의
│  ├─ augments.ts    증강체 정의
│  └─ stages.ts      챕터/스테이지, 상점 확률
├─ core/          ← 순수 게임 로직 (DOM 없음 → 테스트/서버 이전 쉬움)
│  ├─ battle.ts      자동 전투 시뮬레이션 + 리플레이 이벤트
│  ├─ run.ts         원정 상태 머신 (상점·합성·진화·보상·증강·수입)
│  ├─ synergy.ts     시너지 계산
│  ├─ stats.ts       별/각성 스탯 계산
│  ├─ gacha.ts       뽑기·천장
│  ├─ save.ts        영구 저장 (localStorage)
│  └─ rng.ts         시드 난수
└─ ui/            ← 화면 (프레임워크 없는 바닐라 TS, 나중에 React/Phaser로 교체 가능)
   ├─ app.ts         화면 전환 + 액션 처리
   └─ components.ts  카드/시너지/HP바 렌더러
```

**설계 원칙**: `data`(무엇) / `core`(어떻게) / `ui`(보여주기) 분리.
전투는 결과를 한 번에 계산하고 이벤트 로그를 UI가 재생 → 나중에 애니메이션·PvP 리플레이·서버 검증에 그대로 사용 가능.

## 7. 밸런스 메모
* 전략 상성 조정 손잡이: `data/doctrines.ts`의 tier 수치, `core/battle.ts`의 `OVERTIME_ROUND`
* 단순 그리디 봇(사면 다 사고 다 올림)이 첫 보스(5스테이지)까지 깨고 6스테이지 정도에서 끝남 → 초반 난이도는 적당한 편, 후반은 전략이 필요
* 조정 손잡이: `stages.ts`의 `power`/`star`, `stats.ts`의 `STAR_MULT`, `gacha.ts`의 확률
